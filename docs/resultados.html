    Recuperar datos

    Importar resultados en CSV

    Si el servidor no estaba encendido durante la prueba, cada aplicación guarda un CSV local. Importa ese archivo aquí para calcular las métricas o, si el servidor está disponible, envíalo para que se una a los datos de la clase.

    Se aceptan el CSV exportado por esta página, el generado por las aplicaciones y el archivo de ejemplo. La primera fila debe contener las cabeceras.

    Configuración

    Conexión con el servidor

    Solo es necesario si el servidor se ejecuta en otro equipo o puerto. La dirección vacía significa «mismo origen». Los cambios se guardan en este navegador.

    Ejemplo: http://192.168.1.40:8080.
